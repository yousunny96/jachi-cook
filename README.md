# 소복 AI 레시피 프로토타입

1인분 분량과 조리 단계를 포함한 AI 초안 6개를 제공합니다. 저장된 초안은 API 없이 작동합니다. 기존 AI 생성 금지 조건은 사용자의 최신 요청으로 변경되었습니다. AI 작성 내용은 사람 검수를 완료한 레시피가 아닙니다.

## 실행

- 단일 파일: 전달된 sobok-prototype.html을 브라우저로 열고 요리를 선택합니다.
- 개발 서버: Node.js 22 이상에서 `node server.cjs`를 실행하고 http://127.0.0.1:4173 에 접속합니다.
- 실시간 생성: 서버 실행 환경에 `GEMINI_API_KEY`를 설정합니다. 키를 대화·소스·HTML에 붙여 넣지 않습니다. `GEMINI_MODEL` 기본값은 `gemini-2.5-flash-lite`입니다.
- 키가 없거나 무료 한도가 소진되면 기존 초안을 유지합니다. 무료 여부는 공급자 계정 설정을 확인해야 합니다. 유료 모델로 자동 전환하지 않습니다.

## 파일

`dist/index.html` 화면 진입점, `app.js` 화면 동작, `styles.css` 스타일, `data.js` 카탈로그와 캐릭터, `recipe-drafts.js` AI 조리 초안, `model.js` 추천·저장, `assets/` 이미지입니다. `server.cjs`는 정적 파일과 선택형 생성 API를 제공합니다. `docs/sobok-developer-spec.md`가 최신 명세입니다.

## 생성 처리

클라이언트는 recipeId만 보냅니다. 서버가 카탈로그에서 재료와 도구를 확인하여 Gemini에 전달합니다. 응답은 ID·형식·길이를 검사하고 화면에서는 HTML이 아닌 텍스트로 출력합니다. 의미상 정확성이나 안전성 검증을 대체하지 않습니다. 기본 손도구와 물은 모든 레시피의 기본 준비물입니다.

성공 캐시 24시간, 외부 호출 분당 5회·24시간 30회, 서버 제한 20초입니다. 메모리 기반이라 재시작 시 초기화됩니다. 로컬 검토용 서버이므로 공개 배포 전 공유 제한·인증·콘텐츠 검수를 추가해야 합니다. 생성된 레시피는 탭을 새로고침하면 번들 초안으로 돌아갑니다.

## 검증

`node --test tests/*.test.cjs`

API 실제 응답 대신 모의 응답으로 키 없음·잘못된 ID·구조 검사·캐시·한도를 확인합니다. 실제 API 키와 운영 배포는 포함되지 않았습니다. 무료 구간 참고: https://ai.google.dev/gemini-api/docs/pricing#gemini-2.5-flash-lite
