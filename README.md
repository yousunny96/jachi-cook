# 🍳 자취 냉장고 레시피

자취생을 위한 요리 가이드. 냉장고에 있는 재료를 입력하면 **지금 만들 수 있는 요리**와 **재료 하나만 더 있으면 되는 요리**를 난이도별로 알려줍니다.

## 기능

- 재료 입력 (쉼표·띄어쓰기로 여러 개 한 번에, 자동완성 지원)
- 비슷한 이름 자동 인식: `달걀 → 계란`, `삼겹살 → 돼지고기`, `스파게티 → 파스타면` 등
- 난이도 3단계: ⭐ 초간단 / ⭐⭐ 보통 / ⭐⭐⭐ 도전
- "기본양념은 있다고 치기" 옵션 (소금·설탕·간장·식용유·고추장·된장 등)
- 카드를 누르면 조리 순서 표시, 부족한 재료는 `+ 재료`로 표시
- 입력한 재료는 브라우저에 저장됨

## 실행

빌드 없이 `index.html`을 브라우저로 열면 됩니다.

```bash
# 또는 간단한 서버로
python3 -m http.server 8000
# → http://localhost:8000
```

## 테스트

```bash
node test.js
```

## 레시피 추가하기

`recipes.js`의 `RECIPES` 배열에 항목을 추가하세요.

```js
{
  name: "요리 이름", level: 1, time: 10,   // level: 1 초간단, 2 보통, 3 도전 / time: 분
  main: ["꼭 필요한 재료"],
  sub: ["있으면 좋은 재료"],
  steps: ["1단계", "2단계"],
}
```

같은 재료의 다른 이름은 `matcher.js`의 `ALIASES`에 추가하면 됩니다.
