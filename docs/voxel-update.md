## 룰렛 뽑기 · 2026-10-20

- 랜덤 뽑기는 부엌 오른쪽 위의 룰렛 아이콘 + "랜덤 뽑기" 글자 버튼이다(하단의 큰 버튼은 없앴다).
- 누르면 룰렛 창이 버튼 쪽에서 커지며 열린다. 후보(바로 만들 수 있는 요리가 5개 이상이면 그중, 아니면 1~2개만 사면 되는 요리까지)에서 최대 8개를 바퀴에 올리고, 3.4초 돌아 포인터 아래 요리로 멈춘다. 멈추면 바퀴가 작아지고 결과가 나온다.
- 결과: 음식 그림·찜 하트·이름·난이도/시간/도구·부족 재료, 그 아래 "레시피 보러 가기", "다시 돌리기(n회 남음)", YouTube 영상, 네이버 블로그 링크.
- 다시 돌리기는 룰렛을 열 때마다 3회. 같은 바퀴에서 직전 결과를 빼고 다시 고른다. 3회를 다 쓰면 버튼이 비활성화된다.

## 하단 버튼 정리 · 2026-10-20

- 하단 버튼은 두 개다: 왼쪽 "요리 랜덤 돌리기"(룰렛 아이콘), 오른쪽 "레시피 추천"(펼친 책 아이콘). 둘 다 아이콘 + 글자 + 작은 설명(후보 수 / 바로 n · 1~2개 사면 n).
- "랜덤 뽑기" 명칭은 "요리 랜덤 돌리기"로 바꿨다(버튼, 룰렛 창 제목). 부엌 위의 룰렛 아이콘은 없앴다.
- "레시피 추천"을 누르면 패널 하나에 "바로 만들 수 있어요"(최대 4개, 2열)와 "1~2개만 사면 돼요"(최대 4개, 1열)가 차례로 나온다. 맨 아래 "요리책에서 전체 보기".
- 후보가 하나도 없으면 "요리 랜덤 돌리기"는 비활성화된다.
- 룰렛이 멈추면 룰렛과 안내 문구는 사라지고 결과만 보인다. "다시 돌리기"를 누르면 룰렛이 다시 나타나 돈다.
- 룰렛 칸 이름은 한 줄 최대 6자, 띄어쓰기 기준으로 최대 2줄까지 보여 주고, 그보다 길면 둘째 줄 끝을 …로 줄인다(현재 30개 메뉴는 모두 2줄 안에 들어감). 오른쪽 절반 칸 글자는 뒤집어 바로 읽히게 했다.

## 2026-10-21 · 친구 픽셀 그림 교체, 4명 제외, 요리책 4개 탭
- 친구 그림을 사용자가 준 픽셀 그림(`assets/characters-pixel.webp`, 1774×887, 배경 원래 투명)으로 교체. 친구마다 그림 안 영역을 재서 `crop`에 넣음(예전 3열 격자 계산 제거). 아바타는 발이 아래에 닿도록 `preserveAspectRatio="xMidYMax meet"`.
- 풍뎅이·고블린·갑옷아저씨·아노코 제외 → 8명(치이카와, 하치와레, 우사기, 시사, 모몽가, 랏코, 쿠리만쥬, 카니). 저장된 친구가 제외된 친구면 하치와레로 돌아감(기존 normalizeState). 친구 고르기는 4명씩 2줄.
- 요리책: 탭 4개 `전체 / 한식 / 일본식 / 즐겨찾기`(개수 표시). 제목 옆 찜 버튼 제거. 즐겨찾기 탭에서는 난이도 줄 숨김. 앱 문구 '찜' → '즐겨찾기'(하트 버튼 설명, 알림, 빈 화면).
- 테스트: 친구 수 기대값 12 → 8.
- 확인: 친구 8명 모두 그림 정상, 탭 전환 정상, 360px 화면에서 탭·친구 카드 넘침 없음, 콘솔 오류 없음.

- 친구 고르기 화면의 "○○의 말투 미리보기"(그림 + 말풍선 + 상황 탭 3개) 섹션 삭제. 관련 `preview-situation` 동작과 `previewSituation` 상태도 정리.
