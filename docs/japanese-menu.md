# 일본 가정식 30개 추가 · 2026-10-20

기존 30개(한식)를 유지하고 일본식 30개를 더해 총 60개다. 일본식은 1인분 개발용 **AI 초안**이며 난이도·시간·분량은 실제 조리 검수 전이다(`source:'ai-draft'`, `humanReviewed:false`).

## 파일
- `dist/data-japanese.js`: 새 재료 21개, 새 양념 8개, 일본식 레시피 30개(분량·물·조리 단계·팁 포함). `data.js`가 불러와 기존 목록 뒤에 붙인다(없는 ID만 추가).
- `dist/assets/food-atlas-japanese.webp`: 5열 × 6행 그림판. `imageIndex` = 번호 - 1. 칸 경계는 픽셀 분석값(세로 0·268·532·784·1053·1321, 가로 0·192·370·566·750·944·1191)이고, 각 칸을 잘라(clipPath) 옆 음식이 비치지 않게 그린다. 기존 한식 그림판에도 같은 자르기를 적용했다.

## 데이터 규칙
- 레시피마다 `cuisine`(`korean`/`japanese`), `atlas`(`kr`/`jp`), 일본식은 `course`(한 그릇·면·간단 한 끼·한 끼 요리·밥과 함께). `밥과 함께`는 카드·상세에 배지로 보인다.
- 비슷한 재료를 자동으로 같다고 보지 않는다: 닭고기 ≠ 뼈 없는 닭다리살·다진 닭고기, 소고기 ≠ 소고기 불고기용·다진 소고기, 돼지고기 ≠ 얇게 썬·다진 돼지고기, 카레가루 ≠ 고형 카레, 두부 ≠ 연두부 ≠ 순두부, 김 ≠ 건미역, 면 종류끼리도 서로 다름. 대체 규칙은 아직 없다.
- 기존 ID를 그대로 쓴 재료: 밥, 계란, 양파, 대파, 당근, 감자, 양배추, 시금치, 마늘, 버터, 우유, 베이컨, 식빵, 김, 두부, 스파게티면(파스타면), 버섯(양송이 포함), 돼지고기(카레용).
- 분류(기존 앱 기준을 따름): 요리의 몸통이 되는 루·가루·면은 **식재료**(고형 카레, 고형 하야시 루 — 기존 카레가루·짜장가루와 같음), 장·액상 소스·조미료는 **양념**(미림, 과립 다시, 농축 멘츠유, 미소, 깨, 야키소바·오코노미야키·우스터소스). 요청서에는 고형 카레·하야시 루가 '양념'으로 적혀 있었지만 기존 분류와 맞추려고 식재료로 두었다.
- 물은 `water`에만 적고 냉장고·부족 개수에 넣지 않는다(상세의 재료 목록 끝에 "기본 준비물"로 표시). 멘츠유는 제품마다 농축 배수가 달라 고정 희석 비율을 쓰지 않는다.
- 그림 속 고명(가쓰오부시, 아오노리, 붉은 생강 등)은 필수가 아니다. 히야얏코는 `tools: []`라 도구가 없어도 추천된다.
- 함박스테이크는 계란을 1큰술만 쓴다. "다 만들었어요"에서 계란 체크를 풀면 냉장고에 남는다.

## 화면
- 요리책 위에 분류 필터 `전체 60 / 한식 30 / 일본식 30`. 난이도·찜 필터와 함께 적용되고, "전체 메뉴 둘러보기"도 분류를 따른다.
- 홈 추천·룰렛은 분류와 관계없이 60개 전체에서 고른다.
