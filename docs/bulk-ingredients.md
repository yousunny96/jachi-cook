# 재료 한꺼번에 담기 · 2026-10-20

냉장고 검색창에 여러 재료를 적으면(예: `계란 2개, 대파랑 양파 두부 한 모`) 검색 결과 대신 "여러 재료를 인식했어요" 패널이 나온다.

## 동작
1. **앱 안 인식(항상)** — `model.parseIngredientText(text)`
   - 숫자+단위(2개, 300g, 1팩…)와 "한 판·두 개" 같은 수량, "이랑·하고·랑·그리고" 같은 연결어를 지운다.
   - 쉼표·줄바꿈·슬래시 등으로 나눈 뒤, 재료 이름과 별칭 중 **가장 긴 것부터** 맞춘다(양파 ≠ 파, 고추장 ≠ 고추).
   - 결과: `{ingredients, condiments, unknown}`. 비슷한 재료로 바꾸지 않는다(삼겹살은 unknown).
2. **AI 보조(못 찾은 말이 있고 서버가 있을 때만)** — `POST /api/ingredients {words:[...]}`
   - 입력이 멈추고 0.7초 뒤 한 번 묻는다. 냉장고·캐릭터 정보는 보내지 않는다.
   - 서버는 단어 1~12개(각 30자 이하)만 받고, Gemini 응답 중 **물어본 단어 + 등록된 식재료 ID**만 통과시킨다. 24시간 캐시, 기존 레시피 생성과 같은 요청 한도(분당 5 · 하루 30)를 함께 쓴다.
   - 키가 없거나(503) 단일 HTML 파일로 열면 "AI 연결이 없어 앱이 아는 이름만 찾았어요"로 안내하고 앱 인식 결과만 쓴다.
3. **확인 후 담기** — 인식한 재료는 버튼으로 보여 주고(AI가 찾은 것은 `AI` 표시), 하나씩 눌러 빼거나 넣을 수 있다. "인식한 재료 n개 한꺼번에 담기"를 누르면 담은 목록에 추가된다. 냉장고에 실제로 저장되는 건 기존처럼 "저장하기"를 눌렀을 때다.
   - 양념(간장, 미림 등)은 냉장고가 아니라 내 주방 항목이라 "양념도 내 주방에 담기" 버튼으로 따로 담는다(바로 저장).
   - 못 찾은 말은 빨간 상자에 보여 준다.

## 확인
`tests/bulk-ingredients.test.cjs` 5개: 수량·조사 제거, 긴 이름 우선과 양념 분리, 모르는 말 처리, AI 입력 거절(키 없음·형식·크기·출처), AI 응답 검증과 캐시. 실제 Gemini 호출은 API 키가 없어 검증하지 않았다.
