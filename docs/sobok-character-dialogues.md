# 소복 · 캐릭터별 말풍선 시안

첨부된 성격표를 바탕으로 서비스에 맞게 새로 작성한 문구입니다. 원작의 공식 대사를 인용한 것은 아닙니다.

메인 시안의 선택 캐릭터는 하치와레입니다. ‘친구 바꾸기’에서 12종 중 한 캐릭터를 선택하는 화면으로 구성했습니다.

| 캐릭터 | 표현할 성격 | 부엌에 들어왔을 때 | 요리를 고를 때 | 요리를 마쳤을 때 |
|---|---|---|---|---|

## 화면 적용

- 메인: 선택한 캐릭터 한 명과 말풍선 하나를 보여줍니다.
- 친구 선택: 캐릭터 이름·성격 한 줄·선택 표시와 말투 미리보기를 보여줍니다.
- 말풍선은 현재 상황에 맞게 바뀌며, 냉장고와 내 주방 버튼을 가리지 않게 배치합니다.
- 주방은 냉장고, 조리대, 작은 식탁, 창문을 중심으로 단순화했습니다.

현재 결과물은 화면 디자인 이미지이며 실제 선택 동작을 구현한 웹앱은 아닙니다.
